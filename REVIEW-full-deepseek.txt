──────── Project Summary ────────

### Top Issues

1. **Open-redirect / path-sanitization bypass in auth flows.** Redirect targets are built from untrusted Host/`x-forwarded-host`/Origin request data, and the `next` path is not validated as a same-origin relative path. `lib/safePath.ts` accepts percent-encoded separators and dot segments (`/%2f%2fevil.com`, `/%2e%2e/…`), and `app/[locale]/signin/page.tsx` sanitizes before stripping the locale, which defeats the `//` guard. Affected: `app/auth/callback/route.ts`, `app/[locale]/signin/actions.ts`, `proxy.ts`, `lib/safePath.ts`, `app/[locale]/signin/page.tsx`, `app/[locale]/filiere/page.tsx`.

2. **Device-local student data is neither isolated nor validated.** Progressive/activity/onboarding/filière keys are not scoped to the current account owner, and several write paths bypass `deviceIsSealed()`. JSON from `localStorage` is cast to typed shapes without runtime validation, and prototype-chain `in` checks accept `"constructor"`/`"toString"` as valid values. One student can read/credit another student's data on a shared machine. Affected: `lib/activity.ts`, `lib/courseProgress.ts`, `lib/onboarding.ts`, `lib/filiere.ts`, `lib/selfCheck.ts`, `components/quiz/SelfCheck.tsx`, `components/SyncProvider.tsx`.

3. **Sync paths can silently lose or corrupt progress.** `lib/sync.ts` destroys device-local keys before attempting the archive write and ignores the write result; `remoteIsNewer` ignores the local attempt timestamp; `local.hints` can become `NaN`; and every pulled remote row is marked changed. `components/SyncProvider.tsx` releases the pulling guard after a failed initial pull with no retry and does not clear debounced timers. `proxy.ts` also drops the original query string from the post-login `next` value. Affected: `lib/sync.ts`, `components/SyncProvider.tsx`, `proxy.ts`.

4. **Insecure or self-silencing math/GeoGebra rendering.** `components/math/MathContent.tsx` enables KaTeX `trust: true` and uses reachable-by-comment but unsafe fallback HTML. `lib/geogebraSpec.ts` lets arrays and arbitrary JSON objects pass as `GeogebraSpec`, and malformed GeoGebra fences silently render nothing in `components/course/CourseDoc.tsx`. `components/quiz/ItemText.tsx` replaces `p` with a fragment and silently degrades bad TeX. Affected: `components/math/MathContent.tsx`, `lib/geogebraSpec.ts`, `components/course/CourseDoc.tsx`, `components/quiz/ItemText.tsx`, `components/math/GeogebraBlock.tsx`.

5. **Supabase/auth error paths leave live sessions or stale cookies.** The callback route redirects without signing out when the exchange succeeds but the user/email is missing; the sign-out route is a cross-site-destructive GET and failed sign-out can leave Supabase cookies intact; OAuth sign-in is not wrapped in a catch; and `lib/supabase/server.ts` swallows all cookie-write failures, not just Server Component calls. Affected: `app/auth/callback/route.ts`, `app/auth/signout/route.ts`, `app/[locale]/signin/actions.ts`, `lib/supabase/server.ts`.

6. **Missing security headers and security-test bypasses.** The app has no CSP and no HSTS layer despite rendering markdown/KaTeX and handling uploads; the E2E bypass falls back to a predictable `e2e-local-only` secret and compares it in non-constant time; CI runs with default GITHUB_TOKEN permissions and placeholder Supabase credentials that let `db:check` skip live RLS/allowlist probes. Affected: `next.config.mjs`, `package.json`, `lib/e2e.ts`, `.github/workflows/ci.yml`.

7. **Operational and test scripts are injection-prone or brittle.** `scripts/events.mjs` interpolates CLI values directly into PostgREST filter syntax, mishandles NULL `event`, non-JSON 2xx bodies, huge/negative limits, and unhandled network rejections. `scripts/whois.mjs` builds a SQL `INSERT` from raw argv with escaping hazards. `scripts/test-course.mjs` hardcodes catalogue totals, dereferences possibly-missing documents/views, and has unhandled Playwright rejections that mask later failures. Affected: `scripts/events.mjs`, `scripts/whois.mjs`, `scripts/test-course.mjs`.

8. **Crawler/SEO and route surfaces disagree with each other.** `app/sitemap.ts` emits the root without a trailing slash and omits `x-default`, while the page head publishes it. `app/robots.ts` collapses dynamic segments so `INDEXABLE_PATHS` can never un-disallow a dynamic route, and it hardcodes private prefixes. `lib/publicPaths.ts` emits canonicals for `/signin` without consulting `INDEXABLE_PATHS`. Locale switching drops query/hash, and locale-stripping logic is duplicated. Affected: `app/sitemap.ts`, `app/robots.ts`, `lib/publicPaths.ts`, `components/landing/LangSwitch.tsx`, `proxy.ts`, `app/[locale]/signin/page.tsx`.

### Cross-Cutting Concerns

- **Unvalidated browser storage everywhere.** `localStorage` reads/writes are scattered across `lib/activity.ts`, `lib/courseProgress.ts`, `lib/onboarding.ts`, `lib/progressTracking.ts`, `lib/selfCheck.ts`, `components/SyncProvider.tsx`, and `components/quiz/SelfCheck.tsx`; they generally lack owner scoping, shape validation, and device-seal checks.
- **`any` and unsafe casts erode type safety.** `eslint.config.mjs` disables `@typescript-eslint/no-explicit-any` repo-wide, and the pattern reappears in `components/math/GeogebraViewer.tsx`, `app/[locale]/layout.tsx`, `lib/e2e.ts`, `lib/geogebraSpec.ts`, and `app/[locale]/signin/actions.ts` (`locale as never`).
- **Broadly missing or too-broad error handling.** Scripts, server actions, and route handlers commonly fail with raw stack traces or silently swallow failures: `scripts/events.mjs`, `scripts/whois.mjs`, `i18n/request.ts`, `app/auth/callback/route.ts`, `app/[locale]/signin/actions.ts`, and `lib/supabase/server.ts`.
- **Accessibility semantics are frequently incomplete.** Dialogs lack accessible names/focus traps, radio/tab roles are under-implemented, progressbars/charts/logos lack accessible names, and icon-only controls remain announced. Representative: `components/course/ChapterComplete.tsx`, `components/onboarding/ChoiceGrid.tsx`, `components/progress/ProgressDashboard.tsx`, `components/progress/ActivityChart.tsx`, `components/CourseCard.tsx`, `components/landing/Logo.tsx`.
- **Hardcoded routes, counts, prices, and catalog data.** Business/route values are repeated in `lib/siteUrl.ts`, `lib/safePath.ts`, `components/onboarding/FiliereGate.tsx`, `app/[locale]/(with-header)/subscribe/page.tsx`, `app/[locale]/(with-header)/progres/page.tsx`, `components/seo/OrganizationSchema.tsx`, and `scripts/test-course.mjs`.
- **Duplicated logic and dead/inert state.** Locale-stripping is copied between `proxy.ts` and `app/[locale]/signin/page.tsx`; the Khatim star geometry is duplicated in `components/landing/KhatimFigure.tsx` and `Zellige.tsx`; `GeogebraViewer` has unused `isReady` and ignored `commands`; `LearningPaths` has inert CTA buttons; `RevisionPlan` stores unread verdicts.
- **Hydration/render-time side effects.** Renders read `localStorage`, mutate maps while rendering, or compute `new Date()`: `lib/activity.ts`, `components/course/CourseDoc.tsx`, `components/Footer.tsx`, `components/StreakCard.tsx`, `components/landing/LangSwitch.tsx`.
