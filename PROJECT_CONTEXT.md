# Zabaqist Project Context

## Project Overview

**Zabaqist** is an interactive educational platform specifically designed for Moroccan students learning mathematics. Inspired by Brilliant.org's approach to STEM education, the platform combines interactive learning with competitive quiz elements, focusing on the Moroccan mathematics curriculum.

## Core Concept

Think of it as **"Brilliant.org meets Kahoot for Morocco"** - an interactive learning platform that merges:
- Self-paced, visual problem-solving (like Brilliant.org)
- Real-time, competitive quiz gameplay (like Kahoot)
- Moroccan mathematics curriculum delivery
- Arabic and French language support
- Social/multiplayer learning features tailored for Moroccan students

## Brand Identity

**Name**: Zabaqist (زبّاقيست)
**Target Audience**: Moroccan students learning mathematics
**Languages**: Arabic and French
**Mission**: Making mathematics engaging and accessible for Moroccan learners through interactive, competitive learning experiences
